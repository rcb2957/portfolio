# Portfolio Site

A personal portfolio website built to showcase my projects, work experience, and shed some insight into me as a software developer.
People who visit my site can learn about me, explore my work, or find means of connecting with me.

## Overview

This portfolio features my accomplishments, provides information about my work experience and projects, and offers easy access to my GitHub, LinkedIn, and professional email.

- About Me Section
- List of Past Projects
- List of skills, technologies, and programming languages I use
- Work Experience Section
- Link to Verified Cerification
- Links to my personal GitHub and LinkedIn
- Downloadable Resume
- Light and Dark Mode Toggle
- Responsive design for desktop and mobile
